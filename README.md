# Ichrak Ben Tej — Portfolio

Live site: https://ichrak-ben-tej.github.io

## Add gallery photos
1. Upload your photos into the `images/` folder (e.g. `photo7.jpg`).
2. Edit `index.html`, search for `const GALLERY`, and set each `src`, e.g. `src: 'images/photo1.jpg'`.
3. Commit. The site updates in about a minute.

File names are case-sensitive: `Photo1.JPG` is not the same as `photo1.jpg`.
